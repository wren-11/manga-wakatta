# MangaBubble

[English](README.en.md)

Chrome 插件：截图识别漫画对话框，把译文直接盖在原文上。支持翻成简体中文、繁体中文、英文。

只读取屏幕上的画面，honto 这类在线阅读器也能用。

## 安装

1. [下载 ZIP](https://github.com/wren-11/manga-bubble/archive/refs/heads/main.zip)，解压，把 `manga-bubble-main` 文件夹放在不会误删的地方。
2. Chrome 打开 `chrome://extensions`，打开右上角“开发者模式”。
3. 点左上角“加载未打包的扩展程序”，选这个文件夹。

更新：下载新的 ZIP 覆盖旧文件夹，再到 `chrome://extensions` 点插件上的刷新按钮。

## 获取 API key

二选一：

- **通义千问**：国内首选，北京地域新用户有 100 万 token 免费额度（约 200 页）。
- **Claude**：效果最好，按量付费。

### 通义千问

1. 登录 [阿里云百炼](https://bailian.console.aliyun.com)，开通百炼。
2. 在“模型”里搜 `qwen3-vl-plus`，点进去，打开 **“免费额度用完即停”**（默认关闭，不打开会自动扣费）。
3. 点左下角“API-KEY”，创建 key 并复制。
4. 右键插件图标 →“选项”，选“通义千问”，粘贴 key，保存。

**查看剩余免费额度：** 百炼控制台 →“模型”→ 搜 `qwen3-vl-plus` → 点进去，“免费额度”一栏会显示剩余多少 token 和到期时间。一屏（左右两页）大约用 8,000 token。

**免费额度用完后继续用：** 在阿里云“费用中心”充值，再回到 `qwen3-vl-plus` 页面关掉“免费额度用完即停”，key 和插件设置都不用改。北京地域一屏约 2 分钱，充 10 元大约能翻 1,000 页。余额用完会变成欠费，记得留一点余额。

**在海外使用：** 翻译速度和你离服务器的距离有关。人在海外却用北京地域，每页要等 10–20 秒；换成离自己近的地域（比如在澳洲、东南亚选新加坡），大约 5 秒就能翻完。
切换方法：在控制台顶部把地域换成离你近的那个，在该地域下创建 key，再复制 Base URL 里的“OpenAI 兼容地址”，把 key 和地址一起填进插件设置。
中国站账号只有北京地域有免费额度，其他地域按量计费（一屏约 2–3 分钱）。按阿里云官方说明，[国际站](https://www.alibabacloud.com)新注册的账号在新加坡地域有免费额度。

### Claude

1. 登录 [platform.claude.com](https://platform.claude.com)，在 Billing 里充值。Claude Max / Team 会员可以在 claude.ai 的 Settings → Billing → API credits 里绑定，使用每月赠送的额度。
2. 在 API Keys 里创建 key 并复制。
3. 右键插件图标 →“选项”，选 Claude，粘贴 key，保存。

key 只保存在你的浏览器里，不要发给别人。

## 使用

设置保存后直接生效，不用重新加载插件。如果漫画页面在安装插件之前就已经打开，先刷新一下页面。

打开漫画，点插件图标或按 `Option + T`（Windows：`Alt + T`）。

- 翻页后会自动翻译新的一页，可以在设置里关掉。
- 同一页翻过一次不会重复收费。
- 快捷键可以在 `chrome://extensions/shortcuts` 修改。

如果装了“沉浸式翻译”这类网页翻译插件，请把漫画网站设成“不翻译”，否则它会把译文再翻一遍。

## 设置

- **翻译成**：简体中文 / 繁体中文 / 英文
- **译文框**：“只盖住原文”不挡画面；“自动撑大”字更清楚，但会挡住一部分画面
- **最大字号**：小 / 中 / 大
- **翻页后自动翻译**：默认开启

## 常见问题

- **点图标没反应**：`chrome://` 页面不能用。刚装好插件的话，先刷新漫画页面。
- **key 无效**：检查是否复制完整。通义千问的 key 和 Base URL 要在同一个地域。
- **欠费或额度用完**：到阿里云充值，或者回到北京地域使用免费额度。
- **框的位置不准**：AI 给的位置偶尔会偏，用 Claude 会好一些。

## 已知问题

- 译文是白底框盖在原文上，没有抹掉原文。
- 偶尔会漏掉一两句，或者框的位置偏移。
- 只翻译当前窗口里看得到的部分。

## 隐私

截图只发给你选的 AI 服务，插件没有自己的服务器。
